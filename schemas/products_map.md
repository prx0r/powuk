# Downstream products — deliberately not build priority

The gardens enable these later without changing their core collection design.

- POW research terminal
- scarcity / constraint API
- repair economics API
- parts procurement intelligence
- flipping/resale intelligence
- UK skills/capacity maps
- grid constraint maps
- company physical-exposure engine
- reverse fundamental scanner
- Seesaw backtester
- market assimilation research
- YouTube/content generator based on measured stories
- Muse primitive
- agent/MCP tools
- historical data licensing where rights allow

## Rule

Do not let a downstream product dictate deletion of raw evidence or collapse the ontology prematurely.

The garden is primary.
Views/products are disposable.

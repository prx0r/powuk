# pow-frontier

## Mission

Not “tech news.”

Its job is:

> Detect credible technical changes that could alter a binding constraint, then emit structured Seesaw hypotheses for other gardens to test.

## Canonical filter

A story enters POW only if we can answer:

1. What constraint might this relax?
2. By what mechanism?
3. What becomes relatively scarcer/more valuable?
4. What observable predictions follow?
5. What would kill the thesis?
6. Which garden metrics can test it?

## Domains

Initial watch:
- compute architecture
- thermodynamic/probabilistic compute
- quantum
- memory/interconnect
- robotics
- sensors
- actuators
- batteries/power electronics
- manufacturing/semiconductor process
- energy/grid
- cryptographic/decentralized physical-resource networks

## Output

`frontier_event` and `SeesawHypothesis`, not generic articles.

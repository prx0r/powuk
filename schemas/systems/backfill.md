# Backfill

Highly backfillable:
- papers
- Crossref metadata
- OpenAlex metadata
- patents
- GitHub release/tag history

Collect now for:
- official project announcements that may change
- benchmark pages
- pricing/product availability
- repo state that can be rewritten/deleted
- exact observed-at timestamps for POW's own knowledge state

Even for backfillable events, `observed_at` matters:
the research question is sometimes “when could POW have known?”
